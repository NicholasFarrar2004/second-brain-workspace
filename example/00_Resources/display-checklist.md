# Fictional display review checklist

Reference material for the poster-display demonstration. This document describes a review process, not its completion status.

1. Read the current project constraints before evaluating the layout.
2. Check every caption for a matching poster title, consistent spelling and complete text.
3. List unresolved corrections explicitly. A pending caption does not count as approved.
4. Prepare an installation checklist covering poster order, board placement and a final visual inspection.
5. Update the project handoff with the actual outcome and next action.

Current work is recorded in [the poster-project handoff](../Areas/Exhibit%20Projects/Poster%20Display/Handoff.md).
