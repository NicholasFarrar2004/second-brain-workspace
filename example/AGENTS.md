This is an invented demonstration workspace. No example action authorizes work in a real project.

Select a declared route in [workspace.json](workspace.json), then read the common instructions, applicable area and project records, and the route's explicit references. Use narrower instructions for details of that project. If instructions conflict, identify the conflict rather than silently choosing a convenient interpretation.

Keep rules in the instructions for their scope, durable facts in the narrowest owning memory, and the current task state in its handoff. Link to an owning record instead of duplicating it. Read [workspace facts](MEMORY.md) for context about this example.
